# NextXus Process

How the Federation builds and runs. This page documents the two-layer architecture, the cause-and-reaction evolution model, the build workflow, and the operating rules every Federation build follows. For builders, and for anyone who wants to understand how the Federation stays running.

**Live:** https://keywebco.github.io/nextxus-process/

## What the page covers

- **The two-layer architecture** — the silent technical layer does the work and repairs itself; the voiced persona layer speaks to humans.
- **Cause and reaction** — the Federation's evolution model: every change is a cause, every result a reaction to learn from.
- **The build workflow** — how a build moves from idea to live.
- **Operating rules** — the standing rules every Federation build follows.

The two-layer pattern is the Federation's standard: Nova bots and the Agent Zero middleware work silently underneath; the Nova AI persona and Spine speak to humans on top.
